# 🕹️ Core Game Mechanics & Features
* 1. Active & Passive Click EconomyClick Power: Boost active tap values instantly using the core click pad interface.Auto-Clickers:  Automate incremental progression loops at +1 click/sec increments. Quantum Chips: High-tier resource engines generating +5 clicks/sec production arrays.
 * 2. Rapid Combo EngineMaintain a rapid clicking rhythm to activate temporary global multiplier stacks. Includes a built-in bonus progress calculator updating values in real-time.
* 3. Anti-AI Scraping "Camouflage Server Time Cloaking Feature: Utilizes local context-masked font parameters to make critical game loops" and verification timestamps difficult for automated scrapers or AI web interpreters to extract cleanly, protecting individual progress pools.Automated UTC Timekeeping: Uses client-side relative browser date metrics (.toUTCString()) to guarantee synchronization without creating an external network payload footprint.
* 4. System Settings & CustomizationHigh Contrast Theme Toggle: Instantly switches structural color palettes from a deep navy canvas to a stark, high-visibility white theme interface.Developer Cheat Codes Engine: Access a backend testing prompt to skip early gameplay balancing.
